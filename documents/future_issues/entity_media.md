# Entity Media (Pictures and Maps)

## Objective

Allow entities to have attached images — photos, illustrations, or sub-maps. A forest can have a picture, a country can have a detailed political map, a city can have a street-level map. Images are displayed as clickable miniatures in the sidebar's detail view. Clicking a miniature either opens a full-size preview or, if the image is a map registered in the system, navigates the user directly to that map. This connects the macro and micro levels of worldbuilding visually.
